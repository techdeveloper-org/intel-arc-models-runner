## Measured Results (generated)

The table below is generated by `scripts/render_bench_docs.py` from the schema-v1 files in `docs/benchmarks/results/`. Method, metric definitions and claim thresholds are in [METHOD.md](METHOD.md).

**Which statistic each cell is.** The value before `+/-` is the **median** of the n timed (non-warm-up) samples. The number after `+/-` is **not** a confidence interval of that median: it is the half-width of the 95% **Student-t interval of the arithmetic mean** (`student_t_ci95`, computed on the same samples). So a cell reads "median +/- (Student-t 95% half-width of the mean)"; the column headers below that say "median +/- 95% CI" are shortened labels from the generator and should be read that way. No bootstrap interval, IQR or non-normality flag is printed here (they can be computed from the result files). Decode tok/s is derived from OpenVINO counters, not read from a separate meter, even where the Source column says `measured`.

## 🖥️ Physical Testbed Hardware Specification

- **Host CPU**: Intel® Core™ Ultra 5 125H (Meteor Lake; 18 logical CPUs per `probe.json`; the core count is not captured by the probe)
- **Host GPU**: Intel® Arc™ Graphics (Xe-LPG integrated GPU; the Xe-core count and XMX/DPAS presence are not captured by `probe.json` and are unverified)
- **Host NPU**: Intel® AI Boost NPU 3720 (power not measured on this testbed)
- **Host RAM**: 15.43 GB total physical RAM (from `scratch/live_real_models_benchmark_results.json`, not from `probe.json`; Windows 11 AMD64 build 26220 per `probe.json`)
- **Driver Stack**: driver versions are not recorded (`driver_versions` is empty in every result file and `probe.json` has no driver version); OpenVINO GenAI 2026.4.1.0 per `probe.json`
- **Measured so far** (result files): Qwen2.5-1.5B (LLM, GPU/NPU/CPU), Whisper-tiny (STT, GPU/CPU), Qwen2-VL-7B (VLM, GPU/CPU). Embeddings, image, video and an Ollama baseline are not yet measured, and no real 32B/72B run exists.
